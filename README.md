## Open Source — Syzygy

All open-source work has moved from personal `aks5686/*-boilerplate` repos to the **[Syzygy-Hub](https://github.com/Syzygy-Hub)** org — a cross-platform mobile ecosystem of starter templates and UI component libraries spanning all four major mobile stacks.

### Base templates

| Repo | Stack | Description |
|------|-------|-------------|
| [syzygy-base-ios](https://github.com/Syzygy-Hub/syzygy-base-ios) | Swift · SwiftUI · Clean Architecture · MVVM | Production-ready iOS boilerplate with Clean Architecture, MVVM, SwiftUI, Swift 6 concurrency and GitHub Actions CI/CD. |
| [syzygy-base-android](https://github.com/Syzygy-Hub/syzygy-base-android) | Kotlin · Jetpack Compose · Clean Architecture · MVVM | Production-ready Android boilerplate with Clean Architecture, MVVM, Jetpack Compose, Kotlin Coroutines and GitHub Actions CI/CD. |
| [syzygy-base-rn](https://github.com/Syzygy-Hub/syzygy-base-rn) | React Native · TypeScript · Clean Architecture · MVVM | Production-ready React Native boilerplate with Clean Architecture, MVVM, TypeScript, async/await and GitHub Actions CI/CD. |
| [syzygy-base-flutter](https://github.com/Syzygy-Hub/syzygy-base-flutter) | Flutter · Dart · BLoC · GoRouter | Production-ready Flutter boilerplate with Clean Architecture, BLoC, Dart, GoRouter and GitHub Actions CI/CD. |

### UI component libraries

| Repo | Stack | Description |
|------|-------|-------------|
| [syzygy-ui-ios](https://github.com/Syzygy-Hub/syzygy-ui-ios) | Swift · SwiftUI | Production-ready SwiftUI component library with semantic design tokens, Dark Mode, Dynamic Type, and zero third-party dependencies. |
| [syzygy-ui-android](https://github.com/Syzygy-Hub/syzygy-ui-android) | Kotlin · Jetpack Compose | Production-ready Jetpack Compose component library with Material 3 design tokens, Dark Mode, and zero third-party dependencies. |
| [syzygy-ui-rn](https://github.com/Syzygy-Hub/syzygy-ui-rn) | React Native · TypeScript | Production-ready React Native component library with design tokens, Dark Mode, and zero third-party dependencies. |
| [syzygy-ui-flutter](https://github.com/Syzygy-Hub/syzygy-ui-flutter) | Flutter · Dart | Production-ready Flutter component library with design tokens, Dark Mode, and zero third-party dependencies. |
